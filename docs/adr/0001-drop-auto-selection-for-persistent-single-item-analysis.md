# 放弃自动选品流水线，转向常驻式单点分析
自动化选品被判定为「选出的品大概率无效且不直观」：`research-core` 的决策函数在多条路径上把「缺少采购、物流、广告、税费、退货和合规成本」写入结论的缺失项，系统在结构上无法回答「这个品能不能做」。决定不再投入自动流水线，改为在用户已经看中某个商品时，就地取其数据并展示证据。
## Considered Options
- **继续投入自动流水线**：扩大阶段覆盖、放宽结论门槛。放弃原因：结论门槛不是瓶颈，缺失的成本输入才是；放宽只会掩盖不确定性。
- **移除流水线代码**：保留 `research-core` 与 `apps/web` 工作台但不再扩展入口。选它是因为回退成本低于删除成本。
## Consequences
- `research-core`、`apps/web` 工作台进入冻结状态，仍可运行但不再获得功能投入。
- `ProductResults.tsx`、`useProductResearch.ts`、`P0OpportunityPanel.tsx` 已无调用方，其中的图表与趋势组件作为新面板的复用来源保留。
- 研究阶段、预算、四维决策等词汇保留在 `CONTEXT.md`，但不再作为主线能力。
