# 面板同时提供侧边栏与页面内两种形态
搜索结果页的「选中」必须注入 amazon.com（ADR-0003），但「展示」可以在两处。决定**两者并存**：侧边栏提供稳定、不受 Amazon 改版影响的常驻视图；页面内浮层提供贴着商品卡片的即时视图。用户自行选择在何处查看，不强制其一。
## Considered Options
- **只在侧边栏展示**：注入职责最小（只识别卡片、上报点击，不渲染 UI），改版影响面最小，实现成本最低。放弃原因：缺少贴着卡片就地展开的即时感。
- **只在页面内展示**：视觉上最接近同类产品的常驻浮层。放弃原因：面板必须与 Amazon 页面布局共存，失败时会遮挡页面元素，且完全暴露在改版风险下。
## Consequences
- 注入脚本需要渲染 UI，而不只是上报选中——ADR-0003 里「把注入限制在最小职责」的初衷被部分放弃，改版影响面随之扩大。
- 两套布局需要同时维护，视觉与交互规范必须一致，否则用户会在两处看到不同的东西。
- 页面内浮层的性能预算成为硬约束：不得阻塞 Amazon 首屏，失败时静默消失而不是留下残影。
- 需要决定默认展示位置与两者的状态同步方式（选中对象、滚动位置、展开状态）。
