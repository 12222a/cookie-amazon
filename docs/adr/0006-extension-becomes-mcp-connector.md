# 扩展改为专用 MCP 连接器

2026-11-16，用户明确要求移除插件内选品功能，只保留供 AI 调用的 MCP 连接工具，并自动连接。此决定替代 ADR-0003、ADR-0004、ADR-0005 中关于扩展注入、侧边栏和浮层作为当前产品入口的决定。

- 发布构建仅包含 background 和 popup；历史研究入口源码及其单元测试保留，但不打包、不注入、不展示。
- 弹窗只负责连接状态、卖家精灵登录入口及一次性密钥设置。卖家精灵的数据能力继续通过 MCP 使用，移除的是插件自身的选品流程和界面。
- 复用原有受限本机桥接和浏览器会话；已保存密钥自动沿用。安装、浏览器启动、后台恢复、服务恢复和密钥更新后自动连接。
- 通过 Chrome alarm 恢复被挂起的 worker，并保持单个轮询器；连接状态必须来自实际桥接结果。
- 首次安装仍需一次性配置匹配密钥和浏览器登录；MCP 客户端启动本机服务，插件不自行启动本机进程。
